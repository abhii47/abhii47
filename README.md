## 🚀 Featured Projects:

### 📱 [Express GraphQL Social App](https://github.com/abhii47/express-graphql-social-app)
A full-featured social media application built with Express, GraphQL, and TypeScript. Similar to Instagram, featuring:
- **Backend Stack**: Express.js + Apollo Server + GraphQL
- **Database**: MySQL with Sequelize ORM
- **Authentication**: JWT-based auth with bcryptjs password hashing
- **Real-time Features**: GraphQL subscriptions with graphql-ws
- **API Type**: GraphQL API with subscriptions support
- **Language**: 100% TypeScript
- **Features**: User authentication, posts, social interactions, real-time updates

**Key Technologies:**
- Apollo Server for GraphQL
- Express 4.x integration
- GraphQL Subscriptions for real-time updates
- WebSocket support (ws, graphql-ws)
- Secure password handling with bcryptjs
- CORS enabled for cross-origin requests
